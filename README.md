# Portfolio Demos

Three runnable starter projects, one per consulting pillar, scaffolded from
the agentic AI learning plan's three portfolio demonstrations. Each runs on
this machine with plain `python3` - no setup step, no credentials, no paid
services.

| Starter | Pillar | Plan demo |
|---|---|---|
| demo-01-research-brief-agent | Agentic AI implementation | Research Brief Agent: evidence, provenance, structured brief, refuses unsupported claims |
| demo-02-ops-exception-triage | Product and ops strategy | Ops Exception Triage: classifies, gathers context, proposes action, pauses before consequential steps |
| demo-03-enablement-coach | AI training and enablement | Enablement Coach: curriculum plus rubric, adaptive practice, progress without personal data |

Open each folder's README for run and extend instructions. These are starting
points to grow into client proof, not finished demos.
